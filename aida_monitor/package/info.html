AIDA64 // REMOTESENSOR

DYNAMIC LCD RENDERER · v0.2.0

直接解析 AIDA64 生成的 RemoteSensor 页面与 SSE 更新，不再依赖固定字段或固定仪表盘。

> FEATURES

  • 标签、Simple 与复合传感器
  • Bar、LG / AG / HG Graph
  • Arc Gauge、图片与 GIF
  • 多页与自动 ReLoad

> SETUP

  1. 启用 AIDA64 RemoteSensor
  2. 设置 Preview 为 320×240
  3. 在设备 WebUI 填主机与端口
  4. 默认地址 192.168.0.232:9999

> COMPATIBILITY

坐标按 320×240 原样显示，不做缩放。RemoteSensor 不输出 SensorPanel 专用 Custom Gauge，请在 AIDA64 LCD Items 中使用 Arc Gauge。Tahoma、Arial 等桌面字体族会映射到设备固件字体。
