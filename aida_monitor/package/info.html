AIDA64 // REMOTESENSOR

DYNAMIC LCD RENDERER · v0.4.0

直接解析 AIDA64 生成的 RemoteSensor 页面与 SSE 更新，并在应用层完成中文 TrueType 字体的透明合成。

> FEATURES

  • RGB565 + A8 应用层页面合成
  • 标签、Simple 与复合传感器
  • 6–96 px 中文矢量文字
  • 粗体、斜体、下划线、删除线、阴影
  • Bar、Graph、Arc、图片与 GIF
  • 多页与自动 ReLoad

> SETUP

  1. 启用 AIDA64 RemoteSensor
  2. 设置 Preview 为 320×240
  3. 在设备 WebUI 填主机与端口
  4. 默认地址 192.168.0.232:9999

> FONT

请在 AIDA64 LCD Items 中统一选择 AIDA Noto Sans SC。管理页可下载设备使用的同款 TTF。坐标按 320×240 原样显示，不做缩放；SensorPanel 专用 Custom Gauge 请改用 Arc Gauge。
